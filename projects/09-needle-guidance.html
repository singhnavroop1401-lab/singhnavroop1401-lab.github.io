Needle Guidance Pipeline: CT Plan to Simulated Robot

How do you get a needle path planned on a medical image into the joint angles of a robot arm? This project builds that chain end to end in software: planning in 3D Slicer, transfer over OpenIGTLink, coordinate conversion, inverse kinematics and execution on a simulated KUKA arm.

Tools
Python · 3D Slicer · OpenIGTLink · MuJoCo · KUKA LBR iiwa 7 R800 model
Scale
About 3,800 lines of code · 100 offline tests
Status
Simulation only. No hardware in the loop.

The pipeline

  • Planning. Entry and target points are set on a CT scan in 3D Slicer.
  • Transfer. The plan is streamed over OpenIGTLink, implemented from the protocol specification.
  • Coordinates. Conversion from the image frame in millimetres to the robot frame in metres.
  • Inverse kinematics. Joint angles are solved with damped least squares.
  • Execution. The motion runs in MuJoCo on a KUKA LBR iiwa 7 R800 geometry model.

Testing

About 3,800 lines of Python with 100 tests that run offline, without Slicer or the simulator running.

What it doesn't do yet

Image-to-patient registration is a placeholder. There is no Unity or C# front end, no VR and no hardware-in-the-loop; the robot exists only in simulation.
